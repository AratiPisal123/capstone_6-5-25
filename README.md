# Capstone Project

## Setup

1. Install Node.js and Maven.

2. Install frontend dependencies:
   ```
   cd frontend
   npm install
   ```

3. Install backend dependencies:
   ```
   cd backend
   mvn clean install
   ```

## Running

1. Start backend:
   ```
   cd backend
   mvn quarkus:dev
   ```

2. Start frontend:
   ```
   cd frontend
   npm start
   ```

3. Open http://localhost:3000
